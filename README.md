## About

This repository contains four Python projects developed for the CODTECH Cybersecurity & Ethical Hacking internship. The projects demonstrate basic security assessment, password evaluation, file integrity monitoring, and vulnerability record management.

## Projects

### Project 1: Port Scanner

**Folder:** `Project-1-Port-Scanner/`

A Python TCP port scanner that checks a specified port range on a target IP address or hostname.

**Features**
- Target IP address or hostname input
- Configurable port range
- Identification of open TCP ports
- Common service labels
- Text report generation

**Run**
```bash
cd Project-1-Port-Scanner
python port_scanner.py
```

Only scan systems you own or have permission to test.

### Project 2: Password Strength Checker

**Folder:** `Project-2-Password-Checker/`

A desktop application that evaluates password characteristics and provides suggestions to improve password strength.

**Features**
- Password input
- Password strength assessment
- Checks and improvement suggestions
- Clear input and results

**Run**
```bash
cd Project-2-Password-Checker
python password_checker.py
```

Use sample passwords for demonstrations. Do not include real passwords in screenshots or reports.

### Project 3: File Integrity Monitor

**Folder:** `Project-3-File-Integrity-Monitor/`

A desktop application that uses SHA-256 hashes to identify changes in files within a selected folder.

**Features**
- Select a folder to monitor
- Create a baseline of file hashes
- Detect modified, new, and deleted files
- Generate integrity reports

**Run**
```bash
cd Project-3-File-Integrity-Monitor
python file_integrity_monitor.py
```

For testing, use a folder containing sample files that you created.

### Project 4: Vulnerability Management Dashboard

**Folder:** `Project-4-Vulnerability-Dashboard/`

A desktop dashboard for recording, viewing, filtering, and managing vulnerability records.

**Features**
- Vulnerability register
- Severity categories
- Status tracking
- Search and filtering
- View details and update records
- CSV export

The sample records are for demonstration purposes and do not represent verified vulnerabilities in real systems.

**Run**

Use the Python filename present in this folder. For example, if the file is named `vulnerability_dashboard.py`:

```bash
cd Project-4-Vulnerability-Dashboard
python vulnerability_dashboard.py
```
